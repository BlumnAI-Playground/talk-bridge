Dev Environment

개발환경 안내

talkbridge-dev.com 은 운영과 동일한 기능을 제공하는 별도 환경입니다. 내부 QA 용도로 운영하며, 필요한 외부 개발사에 한해 메일 신청을 받아 초청합니다.

운영과 동일한 기능 카카오 비즈니스 개발자용 채널 전용 과금 없음 메일 신청 · 한정 제공

먼저 확인해 주세요

개발환경은 공개로 제공하는 기본 옵션이 아닙니다. 상담채널을 처음 연결한다면 대부분 필요하지 않습니다.

운영 환경과 무엇이 다른가요

기능은 같습니다. 연결할 수 있는 채널과 이용 방식이 다릅니다.

이럴 때 유리합니다

  • 개발환경을 운영과 별도로 관리하는 조직
  • 운영 도입 전에 기능을 검토하는 경우
  • 개발자 모드(API · 웹훅) 연동을 운영과 분리해 개발하는 경우

개발자용 채널 만들고 활용하기

개발환경에는 카카오 개발자용 채널을 연결합니다. 서비스에 영향을 주지 않는 테스트용 채널입니다.

심사를 통과한 비즈니스 채널이 먼저 필요합니다

비즈니스 채널이 최소 1개 있어야 개발자용 채널을 만들 수 있습니다. 심사를 통과하지 못하면 개발자용 채널을 운영할 수 없습니다. 심사는 카카오 채널 준비 문서를 참고해 주세요.

  1. 개발자용 채널 만들기

    카카오톡 채널 파트너센터에서 [개발자용 채널 만들기]를 누릅니다. 비즈니스 인증 채널이 있으면 추가 인증 없이 만들 수 있습니다.

  2. 채널 정보 확인

    연결에 필요한 채널 이름, 검색용 아이디(@ 뒤 값), 채널 관리자 휴대폰 번호를 확인합니다.

  3. 개발환경 센터에서 연결

    승인 후 개발환경 센터에서 운영과 같은 순서로 진행합니다. 브랜드 만들기 → 카카오 채널 등록 → 채널 인증 → 상담 받을 곳 연결 → 상담 활성화

연결되면 AI 에게 "내 파트너 정보랑 관리 중인 브랜드 알려줘"라고 물어 확인합니다. 자세한 방법은 AI 앱 연결 문서를 참고해 주세요.

자주 묻는 질문

비즈니스 채널 없이 개발자용 채널을 먼저 만들 수 있나요?

아니요. 심사를 통과한 비즈니스 채널이 없으면 [개발자용 채널 만들기] 버튼이 나타나지 않습니다.

비즈니스 채널 심사를 통과하지 못하면 어떻게 되나요?

개발자용 채널을 만들 수 없어 개발환경에 연결할 채널이 없습니다. 심사부터 통과한 뒤 진행해 주세요.

개발자용 채널도 따로 심사를 받아야 하나요?

비즈니스 인증을 받은 채널이 있으면 추가 인증 없이 만들 수 있습니다.

일반 채널을 개발환경에 연결할 수 있나요?

아니요. 개발환경에는 비즈니스 개발자용 채널만 연결할 수 있습니다. 카카오 도움말의 일반 채널 연결 방법은 챗봇 관리자센터에 해당하는 내용입니다.

개발환경에서 발급한 키를 운영에서 쓸 수 있나요?

아니요. 키는 발급된 환경에 묶여 있어 개발환경 키를 실환경에서 쓰면 401 이 납니다. 그 반대도 같습니다.

운영으로 넘어갈 때 무엇을 바꾸나요?

실환경 센터에서 운영 채널을 연결하고 키를 새로 발급받은 뒤, API 주소, CLI, MCP 커넥터를 실환경용으로 바꿉니다.

참고 링크

  • 카카오톡 채널 파트너센터 →개발자용 채널을 만드는 곳
  • 개발채널 생성 방법 →개발자용 채널 버튼 노출 조건 (챗봇 관리자센터 기준 도움말)
  • 카카오톡 채널 이해하기 →개발자용 채널 공식 설명 (Kakao Developers)
  • 카카오 채널 준비 →비즈니스 채널 심사 안내 (TalkBridge 문서)

이용 절차

별도의 제약 조건 없이 메일로 접수하며, 내용을 검토해 승인합니다.

  1. 개발환경에 가입

    talkbridge-dev.com 에 가입합니다. 이때 사용한 계정을 신청 메일에 적어야 합니다.

  2. 메일로 신청

    가입 계정(필수), 개발환경이 필요한 사유, 도입 준비 중인 플랜을 적어 보냅니다.

  3. 검토 후 승인

    신청 내용을 검토해 해당 계정을 승인 상태로 변경합니다.

  4. 운영과 분리된 환경에서 개발

    카카오 개발자용 채널을 연결해 기능 검토와 개발자 모드 개발을 진행합니다.

실고객 상담에는 이용하지 말아 주세요

개발환경은 검토와 개발을 위한 환경이며 내부 QA 에도 함께 쓰입니다. 실제 고객 상담은 운영 환경에서 진행해 주세요.
