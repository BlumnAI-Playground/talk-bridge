## 규칙

- 디렉터리는 **처음 관찰한 CLI 버전**으로 나눈다 (`v1.0.0/`, `v1.1.0/`). 기존 항목은 새 버전이 나와도 옮기지 않고 상태와 "재검수" 절만 갱신한다. 새 버전에서 **처음** 관찰된 현상만 그 버전 디렉터리에 신설한다
- 문서 하나 = 재현 가능한 현상 하나. 번호는 신설 순서, 재사용하지 않는다
- 모든 현상은 실측 인용. 추정은 "추정" 이라고 쓴다
- 관련 샘플·지식 문서에서 `→ cli-feat/CF-nnn` 로 역링크한다
