## 벤더(CLI)에 전달할 개선 항목

1. 게이트웨이가 DB 를 상시 점유 — 조회 API 제공 또는 쓰기 시점에만 열기
2. `knowledge query` 배치 중 문장 실패가 `(ok)` 로 가려짐
3. `knowledge build` 의 `ts` 가 원 메시지 시각이 아니라 적재 시각
4. `knowledge install/build` 가 AI 미설정을 거부 — AI 없이도 기본 그래프 적재 허용
5. `setup --help` 가 setup 을 실행
6. `knowledge view` 의 `/search` 가 `JsonTypeInfo` 직렬화 오류, `127.0.0.1` 호스트 400
