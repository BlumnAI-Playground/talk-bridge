## 설계 결정

- **트리거 등록 위치**: 모든 트리거가 TalkBridge 고유 용어를 담으므로 표준 `harness-kakashi-creator` SKILL.md 에 넣지 않고
  `harness/agents/*.md`, `harness/engine/*.md` frontmatter `triggers:` 자동 발견에 맡긴다. 프로젝트 전용 스킬은 만들지 않았다
  (`.claude/skills/` 없음 — 필요해지면 `/skill-creator` 로 생성).
- **02-api-webhook 대비**: `webhook.js`·`signature.js` 무수정 재사용 약속을 보안·이식성 에이전트 양쪽의 체크 항목으로 넣어,
  02 가 추가될 때 같은 에이전트가 그대로 검수한다.
- **표준 스킬 연동**: `/security-review`, `/code-review` 를 보조 도구로 명시하되 결과는 하네스 계약 기준으로 재판정한다.
