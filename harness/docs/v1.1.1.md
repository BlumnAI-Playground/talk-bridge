## 실측에서 얻은 사실 (요약)

- Funnel 은 경로 접두 마운트이며 경로를 strip 하지 않는다. 루트를 열지 않으면 `/`·`/api/*` 는 404
- 본문 바이트 무변형 → raw body 서명 검증 그대로 통과. `x-forwarded-for`, `x-forwarded-proto: https` 부착
- 로컬에서 자기 호스트명 호출은 MagicDNS 때문에 tailnet IP 로 가서 실패 — 공개 인그레스로 `--resolve` 해야 진짜 테스트
- 브랜드의 `webhook-domain` 은 `https://webhook.talkbridge-dev.com`(bypass 구성) — 02 의 수신 URL 은 센터 "상담 받을 곳 연결 → Webhook" 에 등록
