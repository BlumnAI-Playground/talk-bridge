# v1.2.1 — 정원지기 네이밍 전환 · 블룸 정원의 하네스 (2026-09-09)

## 요약

플러그인 harness-kakashi 2.1.1 에 맞춰 메타 에이전트 이름을 **카카시 → 정원지기**로,
호출 명령을 `/harness-kakashi-creator` → `/harness-creator`, `/harness-chakra-kakashi` → `/harness-chakra` 로 전환했다.
하네스의 이름을 **블룸 정원의 하네스**로 정하고 루트 README 에 그 이름으로 소개했다.
동작은 바뀌지 않았다 — 이름과 문구만 바뀌었다. Patch 버전.
