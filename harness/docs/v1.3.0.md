# v1.3.0 — Jev 즉답 판정관 영입 + TypeSafe Jev 지식 (2026-09-29)

## 요약

톡브릿지 **간편 FAQ 자동응답** 샘플(Jev 기반, 예정 05) 착수에 앞서, TypeSafe AI 의 System One 모델 **Jev** 를
공식 발표·문서·SDK 소스로 조사해 지식화하고, 이를 설계·검수할 전문가를 영입. Minor — 새 에이전트.

## 변경

- `knowledge/typesafe-jev-system-one.md` 신설 — Jev 정의(생성 없음·보정된 확률), REST API(`/v1/systemone`, `jev-latest`),
  primitive 3종(choice ≤255 / score 2–10 / noul), confidence 정의·권장 구간(>0.9 / 0.5–0.9 / <0.5), 공식 패턴 4종,
  SDK 기본값(참고용 — 샘플은 의존성 0 이라 `fetch`), **간편 FAQ 설계 기준 10조**, 미확인·실측 필요 U1~U6 (한국어 정확도가 1순위)
- `agents/jev-faq-expert.md` 신설 — Jev 즉답 판정관. 설계 모드("jev 설계해") · 검수 모드("jev 점검해", "FAQ 봇 점검해") A~F
- `engine/full-review.md` — 4'. Jev FAQ 검수 단계 (해당 샘플이 있을 때만)
- `engine/targeted-review.md` — Jev/FAQ 파일 라우팅 행
- `harness.config.json` — agents 에 `jev-faq-expert`, version 1.3.0

## 검증

- 조사만 — Jev API 는 아직 호출하지 않음 (지식 문서의 모든 수치는 벤더 문서 기준, `실측` 표기 없음)
